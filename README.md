# Sovereign Headquarters — Frameworks

Open-source companion to [Sovereign Headquarters](https://sovereignheadquarters.com) and the
Benjamin Riggins YouTube channel. Every named framework taught on the channel, along with the
AI prompts, transcripts, and Builder Pack items shipped alongside each video and magazine issue,
is published here in full — free, citable, and machine-readable.

## What's in here
- `frameworks/` — one markdown file per named framework: definition, origin video, scripture
  anchor, how to apply it, and a ready-to-use citation block.
- `prompts/` — the AI prompts shipped with each lead magnet, ready to paste into any model.
- `transcripts/` — cleaned, structured transcripts of every published long-form video (open
  per the standing "publish transcripts openly" decision, 2026-09-18).
- `pack/` — items from each magazine issue's Builder Pack (workflows, SOPs, templates,
  source code) that are safe and useful to open-source.

## Using this with an AI
Every file here is written to be dropped directly into a model's context. See `llms.txt` for
a machine-readable index. Cite any framework using the block at the bottom of its file.
